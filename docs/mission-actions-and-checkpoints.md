# Mission actions and scoring checkpoints

- Live Shooting Action choices are limited to the active player's available **Primary** mission Action. Active Secondary cards do not create Shooting-phase Action choices.
- Secondary mission rules and any Action text remain visible as reference material, but the app does not require the player to record Secondary Action attempts, targets, objectives or completion during live phases.
- At each configured Secondary scoring checkpoint, the app shows the card's scoring requirements and the available VP choices. The physical tabletop and player agreement determine what was completed; the app records the agreed VP and does not infer completion from recorded Actions, objective control, map position or combat history.
- Scoring a Secondary uses the existing player-confirmed ledger operation and existing VP caps. Scored Tactical cards leave the active set through the existing lifecycle. Fixed/Tactical selection, card draw/entry, replacement rules, New Orders and end-of-turn Tactical discard behavior remain unchanged.
- Historical Secondary Action events and supporting evidence helpers are retained for older saved battles, Advisor context and game review. They are no longer required inputs to live Secondary scoring.
- Primary mission Actions remain recordable in Shooting where the selected Primary requires one. Their existing mission-specific state and historical review behavior are intentionally outside the Secondary simplification.
- At end of Command, the active player's due windows are reviewed. At entry into end-of-turn, both the active player's end-of-turn windows and the other player's end-of-opponent-turn windows are shown. At battle completion, end-of-battle scoring is reviewed for both players where applicable.
- Checkpoint transition selection, dialog rendering and manual score controls remain focused modules coordinated by the battle shell.

Validation covers Secondary cards being absent from the live Shooting Action picker, Primary Actions remaining available, Secondary mission summaries presenting Action text as reference only, and known Secondary cards remaining scoreable at the correct checkpoint without any recorded Action history. Physical iPad acceptance is still required.
