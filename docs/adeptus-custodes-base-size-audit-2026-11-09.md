# Adeptus Custodes physical base mapping — 11th edition

Date audited: 2026-11-09

## Coverage

- **36 / 36** datasheet entries currently available in the 40K Tactics Adeptus Custodes army catalog have a mapped physical base type.
- **34** catalog entries use sizes from Games Workshop's **June 2026 Warhammer Event Companion** (31 distinct official guide lines, including aliases for renamed/split datasheets).
- **2** newer kit entries, Gyrfalcon Jetbike Sodality and Caladius Annihilator Grav-Tank, use the sizes supplied with their respective Games Workshop kits, as reported in kit contents; they are **not** claimed to be lines from the June base guide.
- **27** round, **7** oval, and **2** hull-based datasheets.
- Hull means **no standard circular/oval model base size**. Do not fabricate a base for movement or screening.
- An oval size describes one model's physical base, **not** the full footprint of a squad represented by a unit-center marker.

## Orientation / visualization

- Top-down mode scales each marker from the physical mm dimensions against the 60″×44″ board.
- Oval bases retain their major/minor axes. The **Rotate oval** control rotates only the selected oval's *display orientation* by 45° per tap, cycling at 180°.
- Physical SVG outline and marker orientation change together. The unit abbreviation or number and its status badges remain upright. **Drag/selection and Tactical Advisor use the same unchanged map coordinates.**
- A multi-model unit center is a **one-model reference**, shown dashed. It is not the true occupied area until per-model positions are tracked.
- A kit-specific saved manual base size remains authoritative for local display and can be cleared to restore the catalog default.
- Models marked Hull or with unknown/non-Custodes base sizes retain their existing fallback marker; do not infer a base diameter.

- Caladius Annihilator Grav-Tank (150×95mm oval): https://www.miniaturemarket.com/Warhammer-Horus-Heresy-Legio-Custodes-Caladius-Annihilator-Grav-Tank/GW-31-139-2026

**Specific Caladius distinction:** The older GW Event Companion entry for **Caladius Grav-tank** says **170×109mm**, while the **new Annihilator plastic kit** supplies **150×95mm**. They are recorded as separate entries rather than silently equated. Event organisers may specify a newer official revision or base ruling; check their event packet when it differs.

**Completeness scope:** 36 entries means *all datasheets in this app's current Custodes army catalog*, not a claim that GW has no other units or historical kits. Renamed/split datasheets share the matching miniature base from the guide. Imported user-created entries with unknown identifiers are never assigned a guessed base.
